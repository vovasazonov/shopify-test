# Agent guidelines

## Project context

- Read `PLAN.md` and `README.MD` before starting work.
- Follow the priorities and scope in `PLAN.md`: complete A tasks before B; C is optional.
- Keep documentation accurate about what is planned, implemented, and verified.

## Commit messages

Every commit subject must start with exactly one of these five case-sensitive prefixes, followed by a space and a concise description:

- `Add:` for new functionality, files, or documentation.
- `Remove:` for deleting functionality, files, or dependencies.
- `Update:` for changes to existing behavior, configuration, or documentation.
- `Fix:` for correcting a bug or error.
- `Refactor:` for restructuring code without changing its behavior.

Use an imperative description, for example: `Add: project plan and agent guidelines`.
Do not use other commit prefixes.
